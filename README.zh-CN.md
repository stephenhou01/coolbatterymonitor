# CoolBatteryMonitor

**简体中文** · [English](README.md)

一个原生 macOS 电池仪表盘，用 SwiftUI 写成。电池数据直接从 IOKit 读取，显示系统
真正报告的内容 —— 包括系统根本没有报告的地方。

核心原则：**绝不为了填空而编造数字。** 实测值标明是实测，推导值给出算式，数据还不够
的时候显示「正在收集」而不是猜一个。

---

## 界面

### 菜单栏

不打开任何窗口就能看到电量和剩余时间。点击展开面板，显示健康度、当前功耗、循环次数、
温度，以及 CPU 占用最高的几个进程。接电源时，任何续航数字都会明确标注为
**拔电后的预测**，而不是伪装成「剩余时间」。

```
▸ 菜单栏             86%  ·  4:12
  └ 展开面板          健康度 · 功耗 · 循环 · 温度
                     进程排行 · 续航迷你曲线
```

### 仪表盘 —— 五个页面

```
总览        电量 + 三种续航估算 · 能量流向 · 电池状态
            7 张实时指标卡（字段节拍 + 迷你趋势）
技术参数    功耗中心（10 秒功耗曲线 + 进程活动）
            容量解释（设计 / 充满 / 当前 / 耗损）
            官方对比（与 Apple 公布数据比较）
            系统数据工作台（464 字段四层核验）
趋势        实时监测 · 续航历史 · 进程排行 · 充电历史
诊断        健康诊断 · 耗电分析 · 配件检查
            充电习惯 · 系统异常
设置        语言 · 外观 · 菜单栏布局 · 刷新节奏
```

每个指标旁边都有 **?** 按钮，打开后能看到该数值对应的 IOKit 原始字段名、代入数字的
完整算式、这个值的可靠性等级，以及字段最后一次读取的时间。

## 主要功能

**电池健康与容量**
- 电量、健康度、循环次数、温度、各节电芯电压
- 把容量讲成一件连贯的事：出厂设计容量 → 今天能充满多少 → 此刻还剩多少 →
  本次已用掉多少 → 长期损失多少，并且把「暂时取不出来」和「真正老化」分开
- 用循环次数和容量保持率估算电池年龄，明确标注为估算而非硬件解码出的日期
- 支持的机型会与 Apple 公布的电池能量和实验室续航对比，但不把实验室数字说成承诺

**功耗与进程**
- 整机功耗直接读 IOKit，并用三路数据交叉验证
  （`SystemPower`、`SystemLoad`、输入电压 × 电流）
- 10 秒功耗曲线，可暂停/恢复
- 进程按 CPU 排行，**子进程归并到所属 App** —— 一个浏览器或编辑器占一行，
  而不是占三十行
- 同时显示全机 CPU 以及「可见应用 / 系统进程」的拆分：沙箱应用读不到 root 进程，
  这个缺口被明确标出来，而不是藏起来
- **不显示每个进程多少瓦。** macOS 没有提供可靠的进程级功耗，所以这里不编一个出来；
  CPU 和内存只作为负载上下文

**续航估算**
- 电池供电时直接用系统自己的 `TimeRemaining` / `AvgTimeToEmpty`
- 按电量计真实的刷新节奏（约 56 秒）记录有效估算，而不是高频重复采样
- 区分「按 10 分钟中位功耗」和「按当前负载」两种估算，并说明屏幕上是哪一种

**透明度工具**
- 一张经过审核的证据表：原始值、公开值、派生值，附实时数值、合理区间和可靠性等级
- 四层系统核验：464 字段的元数据目录，覆盖 IOPowerSources、
  AppleSmartBattery / IORegistry、旧版 IOPM 和进程信息，并与 macOS 实际返回的
  每一个字段合并。标签页分为有效字段、异常、各来源、全部字段

**充电习惯**
- 周报：充电次数、平均高低电量、充电时最高温度
- 习惯评分只在真正观测够天数之后才出现

## 语言

十种语言，运行时切换，无需重启：

English · 简体中文 · 繁體中文 · 日本語 · 한국어 · Deutsch · Español · Français ·
Italiano · Português

译文按页面维护在 Swift 之外。新增一种语言时，要先在
`Localization/Sources/manifest.json` 注册，再为全部源条目补齐译文并生成对应的自描述 JSON 包。

---

## 运行要求

- macOS 14.0 或更高
- Apple 芯片和 Intel Mac 都支持（两者的温度单位和 CPU 时基不同，均已处理）
- 启用 App Sandbox 和 Hardened Runtime
- **完全没有网络访问**

当前版本：1.2.0

## 从源码构建

Xcode 工程由 `project.yml` 生成，请改这个文件而不是 `.xcodeproj`：

```bash
brew install xcodegen
xcodegen generate
xcodebuild -project BatteryMonitor.xcodeproj -scheme BatteryMonitor \
           -configuration Debug -destination 'generic/platform=macOS' \
           CODE_SIGNING_ALLOWED=NO build
```

这是面向公开仓库检出的可移植无签名编译检查。维护者配置、测试、固定路径、签名、
UserTest 处理和本地发布验证只以 [`QA-RUNBOOK.md`](QA-RUNBOOK.md) 为准；运行任何
签名构建或测试前必须完整阅读该手册。

内置文案按页面/区块维护在 `Localization/Sources/`，运行
`python3 Localization/build-language-packs.py write` 生成十个运行时语言包。新增语言时，
在 `Localization/Sources/manifest.json` 增加语言元数据并为所有源条目补译文；不用改 Swift，也不用重跑
`xcodegen`。生成语言包在运行时仍按不可信输入处理，并以英文包校验格式符。
